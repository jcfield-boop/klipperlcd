==============================================================================
VP ADDRESS SUMMARY
==============================================================================

Event Code:       0x1001  (Word, 2 bytes)  - ALL buttons send events here
Mesh Display:     0x3000  (Text, 800 bytes)
Status Display:   0x3100  (Text, 400 bytes)
PA Display:       0x3200  (Text, 400 bytes)
PA Adjust Value:  0x3201  (Float, 4 bytes)
Shaper Display:   0x3300  (Text, 400 bytes)
Shaper Toggle:    0x3301  (Word, 2 bytes)

==============================================================================
EVENT CODE REFERENCE
==============================================================================

Event 30 (0x1E): VIEW_MESH           - Show bed mesh
Event 31 (0x1F): MESH_PROFILE_SELECT - Load mesh profile
Event 32 (0x20): FIRMWARE_RESTART    - Restart Klipper
Event 33 (0x21): PA_ADJUST           - Adjust PA (needs data from 0x3201)
Event 34 (0x22): PA_RESET            - Reset PA to default
Event 35 (0x23): VIEW_SYSTEM_STATUS  - Show system status
Event 36 (0x24): TOGGLE_INPUT_SHAPER - Enable/disable shaper (needs 0x3301)
